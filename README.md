# 便签待办 · WeChat Todo

把聊天截图变成待办便签的 macOS 原生工具。支持微信 / QQ / 钉钉 / 飞书等所有对话型软件的聊天记录。

## 功能

- **粘贴即识别**：`⌘V` 粘贴聊天截图，本地 OCR 自动生成便签（主题 + 对方账号名 + 需求产生时间 + 相关需求 + 原图）
- **三种输入方式**：粘贴截图 / 内置框选截图 / 拖入图片文件
- **对方账号名自动识别**：优先读取当前前台聊天窗口标题，OCR 兜底识别消息前缀
- **需求时间解析**：自动识别「昨天 下午 3:20」「8月4日」「2026-08-04 10:20」等时间格式，取最后一条消息时间
- **便签样式**：黄纸便签卡片，点击 ○ 完成（划线置灰），点击 × 删除
- **桌面常驻**：贴桌面（不遮挡窗口）或置顶悬浮，未完成待办自动同步到桌面，窗口关闭不退出
- **本地持久化**：数据保存在本地，退出不丢失；完成的事项一周后自动清除

## 使用方法

| 操作 | 方式 |
| --- | --- |
| 系统截图 | `⌃⌘⇧4` 框选聊天记录（直接进剪贴板）→ 回应用 `⌘V` |
| 内置截图 | 点工具栏「📷 截图」→ 全屏框选 |
| 拖入图片 | 把聊天截图文件直接拖进窗口 |

> 首次使用截图功能需在「系统设置 → 隐私与安全性 → 屏幕录制」中授权。

## 构建

需要 macOS 13+ 与 Swift 5.9+：

```bash
./build.sh          # 打包到 dist/便签待办.app
./tests.sh          # 运行解析器单元测试
```

源码入口：`Sources/WeChatTodo/`，核心模块：

- `RequirementParser.swift` — 聊天文本规则解析（时间 / 账号名 / 需求提取）
- `OCRService.swift` — Vision 本地 OCR（完全离线）
- `TodoStore.swift` — 数据持久化与一周自动清理
- `DesktopNotesPanel.swift` — 桌面常驻便签面板
- `ScreenshotCapture.swift` — 内置框选截图 + 聊天窗口标题读取

## 隐私

所有 OCR 与解析均在本地完成，不上传任何数据。
